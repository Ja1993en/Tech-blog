## 📌 Description
The Tech Blog is a full-stack web application that allows users to create, edit, and delete blog posts while staying organized and engaged with other users’ content. This project was built using JavaScript, Node.js, Express, MySQL, Sequelize, and Handlebars.

Users can sign up, log in, and manage their own posts through a dashboard. The application communicates with an Express back-end server and uses a MySQL database for persistent storage.

This project demonstrates how to build a full CRUD application using MVC architecture while integrating front-end and back-end technologies.

## Installation 
Clone the repository:
`git` clone https://github.com/yourusername/tech-blog.git

Navigate into the project directory:
`cd` tech-blog

Install dependencies:
`npm` install

Create a .env file:
DB_NAME=tech_blog_db
DB_USER=root
DB_PASSWORD=yourpassword

Initialize the database:
mysql `-u` root `-p`
SOURCE db/schema.sql;

Run the app:
`npm start`
